# 🌱 HabitFlow

> Consistency is the architect of character.

HabitFlow is a clean, minimal habit tracker built to help you stay mindful and build daily rituals that actually stick — without the clutter.

---

### ✨ What's Inside

- **Daily Rituals** — Track your daily habits and progress with a satisfying, distraction-free flow.
- **Progress & Insights** — Keep tabs on your current streak, completion rates, and momentum.
- **Mindful Design** — Clean layout focused on calm consistency rather than endless notifications.

---

### 🚀 Quick Start

Get it running locally in two commands:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser and start building your flow.

---

### 🛠️ Built With

- **Framework:** [Next.js](https://nextjs.org) (App Router)
- **UI:** [React 19](https://react.dev), CSS Modules & Tailwind CSS
- **Language:** TypeScript
